# QAQ Website

Official website and download page for QAQ, an independent campus life assistant for NTUT students.

## Development

```sh
pnpm install
pnpm dev
```

Production build:

```sh
pnpm build
```

The static output is written to `dist/` and is intended to be deployed to Cloudflare Pages at
`qaq.umeow.eu.org`.
